# Завдання 13. Один список замість трьох рядків (середнє)

Розгляньте два фрагменти.

```python
board = [[0] * 3] * 3
board[0][0] = 1
print(board)
```

```python
original = [[1, 2], [3, 4]]
copy_ = original.copy()
copy_[0].append(99)
print(original)
```

**Завдання.**
1. Автор першого фрагмента чекав `[[1, 0, 0], [0, 0, 0], [0, 0, 0]]`. Що виведе програма насправді? Поясніть причину через поняття посилання та псевдоніма і запропонуйте виправлення.
2. Що виведе другий фрагмент? Чому незмінений, на перший погляд, `original` змінився? Як зробити копію, незалежну від оригіналу?

**Обсяг:** до 10 речень і короткі виправлення коду.

---

Відповідь:У першому фрагменті програма насправді виведе `[[1, 0, 0], [1, 0, 0], [1, 0, 0]]`. Це відбувається тому, що оператор `*` створює три посилання на один і той самий внутрішній список, тобто всі три рядки є псевдонімами одного об'єкта. Тому зміна `board[0][0]` змінює цей список одразу в усіх трьох рядках. Щоб створити незалежні рядки, потрібно використати генератор списків: `board = [[0] * 3 for _ in range(3)]`. У другому фрагменті програма виведе `[[1, 2, 99], [3, 4]]`. Метод `copy()` створює лише поверхневу копію, тому вкладений список `[1, 2]` залишається спільним для `original` і `copy_`. Щоб зробити повністю незалежну копію вкладених списків, можна використати `deepcopy()` з модуля `copy`.
# Виправлення першого фрагмента
board = [[0] * 3 for _ in range(3)]
board[0][0] = 1
print(board)
# Виправлення другого фрагмента
import copy

original = [[1, 2], [3, 4]]
copy_ = copy.deepcopy(original)

copy_[0].append(99)

print(original)
print(copy_)
