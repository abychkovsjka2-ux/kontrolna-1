# Завдання 11. Ім'я і об'єкт: == проти is (легке)

У лекції 1 пояснено, що змінна в Python є іменем, прикріпленим до об'єкта, а не коробкою зі значенням.

**Завдання.** Своїми словами поясніть, чим відрізняються оператори `==` і `is`. У відповіді:
- скажіть, що саме перевіряє кожен із них;
- розгляньте `a = [1, 2]` і `b = [1, 2]`: що дадуть `a == b` та `a is b` і чому;
- назвіть випадок, у якому за стилем Python прийнято писати `is`, і поясніть, чому для порівняння чисел чи рядків `is` не годиться.

**Обсяг:** 5-8 речень.

---

Відповідь:Оператор `==` перевіряє, чи однакові значення двох об'єктів, а оператор `is` перевіряє, чи це саме один і той самий об'єкт у пам'яті. Наприклад, якщо `a = [1, 2]` і `b = [1, 2]`, то `a == b` дасть `True`, тому що списки мають однакові елементи. А `a is b` дасть `False`, тому що `a` і `b` посилаються на різні об'єкти-списки. Оператор `is` за стилем Python прийнято використовувати для перевірки на `None`, наприклад `if value is None:`. Для порівняння чисел або рядків `is` використовувати не потрібно, тому що він перевіряє ідентичність об'єктів, а не рівність їх значень. У деяких випадках Python може повторно використовувати один об'єкт для однакових чисел або рядків, через що `is` може випадково повернути `True`. Тому для порівняння значень чисел, рядків та інших об'єктів потрібно використовувати `==`.
