# Завдання 14. Лічильник, що не рахує (середнє)

Розгляньте код.

```python
total = 0

def add(x):
    total = total + x
    return total

def collect(item, bucket=[]):
    bucket.append(item)
    return bucket

print(add(5))
print(collect(1))
print(collect(2))
```

**Завдання.** Для кожної функції скажіть, що станеться під час виконання, і поясніть механізм (правило пошуку імен LEGB для першої функції; момент обчислення значення за замовчуванням для другої). Запропонуйте виправлені версії обох функцій.

**Обсяг:** до 10 речень і виправлений код.

---

Відповідь:Під час виконання `add(5)` виникне помилка `UnboundLocalError`, тому що через присвоєння `total = total + x` Python вважає `total` локальною змінною функції, але перед використанням вона ще не має значення. За правилом LEGB Python спочатку шукає ім'я в локальній області, потім у зовнішній, глобальній та вбудованій, але в цьому випадку `total` визначається як локальне. Щоб змінювати глобальний `total`, потрібно використати `global total`. У функції `collect()` значення параметра `bucket=[]` створюється лише один раз під час визначення функції, а не при кожному її виклику. Тому `collect(1)` поверне `[1]`, а наступний `collect(2)` поверне `[1, 2]`, оскільки використовується той самий список. Для безпечного варіанта потрібно використовувати `None` як значення за замовчуванням і створювати список всередині функції.

total = 0

def add(x):
    global total
    total = total + x
    return total


def collect(item, bucket=None):
    if bucket is None:
        bucket = []

    bucket.append(item)
    return bucket


print(add(5))
print(collect(1))
print(collect(2))
